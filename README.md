# issance app

Your coding agents on your phone. issance shows every agent running on your computers, sorted by who
needs you, and lets you answer, approve, start new ones and read their output from an iPhone, an Android
phone or any browser. It works over your private Tailscale network, with push notifications.

It runs on your Mac, Windows PC or Linux machine next to Hangar, the runtime the agents live in.

## Install

Use the issance installer for your computer (see the issance-suite README). Then:

```bash
issance start     # start it and print the address and the pairing QR code
issance status
issance stop
```

Open the address on your phone, pair it, and add it to the home screen.
